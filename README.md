# 🏪 Telegram Shop & Marketplace Bot (@AI_Market_BEST_bot)

თანამედროვე ციფრული მარკეტფლეის Telegram ბოტი Binance-ით ბალანსის შევსების და პროდუქტების შეძენის ფუნქციონალით.

---

## 🚀 ფუნქციონალი

1. **🛒 მარკეტფლეისი (Marketplace):**
   - პროდუქტების კატალოგი (მაგ: **ChatGPT Plus (1 Month) — 5.50 $**, Spotify Premium, Telegram Premium).
   - პროდუქტის დეტალური გვერდი: აღწერა, ფასი, Full Warranty (სრული გარანტია).
   - **„🛍️ ყიდვა / Pay“** ღილაკი:
     - თუ ბალანსი საკმარისია: თანხა ავტომატურად ჩამოიჭრება და მყიდველს მომენტალურად მიეწოდება ექაუნთის მონაცემები (Login/Password/ინსტრუქცია).
     - თუ ბალანსი არასაკმარისია: ბოტი აჩვენებს რამდენი აკლია და სთავაზობს Binance-ით შევსებას.

2. **💳 ბალანსის შევსება Binance-ით:**
   - აჩვენებს Binance Pay ID-ს და USDT საფულის მისამართს (BEP-20 / TRC-20).
   - **„📥 შევიტანე (TXID შეყვანა)“** — მომხმარებელს შეუძლია გამოგზავნოს ჩარიცხული თანხა და Transaction ID / ჩეკი.
   - **🧪 სატესტო ბალანსი (+10$ Demo)** — მყისიერად რიცხავს $10.00-ს, რათა დაუყოვნებლივ დატესტოთ ყიდვის სრული პროცესი!

3. **👤 პროფილი და 📦 შესყიდვები:**
   - მომხმარებლის პროფილი: ბალანსი, ID, შეკვეთების რაოდენობა.
   - შეძენილი პროდუქტების ისტორია: ნებისმიერ დროს შეუძლია ნახოს ნაყიდი ანგარიშების მონაცემები.

4. **👑 ადმინ პანელი (`/admin`):**
   - მომხმარებლების რაოდენობა, შემოსავალი, გაყიდვების სტატისტიკა.
   - დეპოზიტების დამტკიცება (Approve) ან უარყოფა (Reject) ღილაკებით.
   - ბალანსის დამატება პირდაპირი ბრძანებით: `/addbalance <user_id> <amount>`.

5. **💾 SQLite მონაცემთა ბაზა:**
   - ჩაშენებული Node.js SQLite (`bot_database.db`), არ საჭიროებს გარე სერვერებს.
   - ინახავს მომხმარებლებს, ბალანსებს, პროდუქტებს, შეკვეთებსა და დეპოზიტებს.

## ⚙️ კონფიგურაცია (.env)

ფაილში `.env` შეგიძლიათ შეცვალოთ:
- `BOT_TOKEN`: თქვენი Telegram ბოტის ტოკენი.
- `ADMIN_ID`: თქვენი Telegram User ID (ადმინ პანელზე წვდომისთვის).
- `BINANCE_PAY_ID`: თქვენი Binance Pay ID.
- `BINANCE_USDT_ADDRESS`: თქვენი USDT საფულის მისამართი.
- `BINANCE_USDT_NETWORK`: ქსელი (მაგ. BEP-20 ან TRC-20).
